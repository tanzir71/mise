# M22 · QR posters and counter cards

Status: software implemented; final CI/Pages verification pending, behind `qrPosters` (default off). Settings → Shop link → QR posters prepares the exact saved customer URL as a scannable PNG. The same artwork prints at A5 (148 × 210 mm) or counter-card size (105 × 148 mm) using the browser's Print / Save PDF flow. Manual copy and opening the PNG remain available.

All 270 exports were checked. Full Figma design context and screenshot for M09 `59:191` were read before implementation, using the design-to-code skill. There are no visible static image assets in this frame: its illustrative rectangles are replaced by the real, dynamic QR matrix. Shared buttons, modal and original Mise QR/download icons supply the controls. The artwork keeps M09's centred shop name, 40px Scan to order, 20px secondary CTA, monochrome surface and Powered by Mise footer. Real shop links require a larger QR than the sample; it occupies a 320-unit square, with smaller gaps. Long shop names wrap and reduce this square only as needed. The unsupported sample table number is replaced by the public phone; later live tracking and payment claims are omitted. The caption correctly describes a WhatsApp request.

The secondary CTA comes from `lang/scan-cta` in the saved shop's market pack. English-only OTHER omits a duplicate secondary line. Geist, Hind Siliguri and Hind are local and explicitly loaded before canvas rendering; Hindi adds one pinned font package to the owner app. The customer build stays isolated. The PNG is 1680 × 2380 pixels with a four-module white QR quiet zone, integer pixel modules and no matrix distortion. QR level M is used when it fits; level L retains exceptionally long complete URLs rather than silently dropping menu information. Overflow is an explicit error with Copy shop link available. There is no shortener, server, schema change or data write.

PDF uses the already-established native browser print approach, preserving identical artwork across PNG, preview and print. Named print pages set the exact paper size and zero margin; other application content is hidden. On phones choose Save as PDF, Actual size and no browser headers/footers. PNG also opens as a local blob in a separate tab for browsers whose download action is unavailable. Object URLs are revoked on cleanup; stale generation cannot replace a newer link.
