The parser preserves complete original source, unknown lines, explicit counts/units, contact fields and fulfilment hints. Damaged or unsupported Mise formats keep all nonempty lines as literal text. Ambiguous quantities, medicine strengths and unrecognised item names remain editable; no catalogue prices are inferred. Source instructions and markup remain text. Relative times are review hints, without an inferred scheduled timestamp. A requested payment never confirms receipt, selects credit or writes money. Cash remains the default.

The pricing editor now accepts a view model without an order ID. Reviewing prices returns edited lines to the normal creation form; it does not save an entity or enable quote sending. Transient line IDs are removed before the audited creation command assigns real IDs. All pre-existing saved-order pricing, revision checks and manual sharing remain available. A matching saved phone exposes both the pasted name and the proposed saved-customer association for review. Header-only requests open manual item entry.

Read clipboard runs only on a tap, and denial keeps manual pasting/typing available. A delayed clipboard result cannot replace newer typed text. The paste field does not silently truncate; requests over 12,000 characters or 200 nonempty lines are rejected with an explanation. The same 12,000-character source limit applies to saves, the editor and backups. Original whitespace and CRLF survive saves and restore; outer whitespace does not prevent M20 format recognition. Existing valid 4,000-character records remain compatible. No schema migration or table is added.
