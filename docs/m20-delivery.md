# M20 · Public shop page and order link

Status: in progress. The public packet, order-message protocol and audited owner-side generation are implemented. The customer page, Settings interface, offline route and page-size acceptance check are still required. `shopLinks` stays off, and M20 stays unchecked.

The public link contains a versioned whitelist: shop name/address/hours, public WhatsApp phone, delivery note, market/currency/timezone and up to twenty explicitly selected catalogue items. It uses lz-string Uint8Array compression and canonical base64url in `/app/s/#<payload>`. No customer, credit, stock, member or audit records enter the payload. Catalogue IDs identify only the selected public items. The decoder bounds the expanded text before parsing, and generation refuses an oversized link rather than dropping items. Both `/app/` and `/mise/app/` destinations are supported.

The existing schema-eight `Outlet.shopLink` stores the generated URL. The owner command checks the exact reviewed shop/catalogue values and previous link within one IndexedDB transaction, then saves the link and attributable audit together. Regeneration retains the shop code, creates a distinct edition even at the same timestamp, and snapshots current menu values. Ten-minute undo restores only the URL, preserves later shop edits, rejects a newer link and records its own audit. Undo cannot revoke links already copied to another device.

English and Bangla messages preserve pickup/delivery, address/time, customer name/phone, all literal item lines, optional payment preference and separate-photo intent. The final `#mise v1` footer adds an explicit photo bit; the handover's older sample remains accepted. A parsed message is an untrusted request, with no paid status or executable instructions. The public formatter has a separate module boundary from the full owner-side phone/parser code.

Focused verification: 35 tests pass, including independent lz-string interoperability, 250 generated UTF-16 decoding cases, malformed/noncanonical input, expansion limits, public-field whitelisting, bilingual message round trips, stale and concurrent generation, audit rollback, scoped/time-limited undo, unchanged private records and exact twenty-table JSON backup/restore.

The foundation passes frozen-lockfile installation, lint, TypeScript/Astro checks, all 358 unit tests, the `/mise/` production build, all 176 browser regressions without retries, all 270 required exports and the visual QA harness's 107 existing comparisons. No visible interface has changed in this increment. CI/Pages evidence follows the push; the milestone's new visual comparisons and public/offline/page-budget evidence belong to the unfinished interface increment.
