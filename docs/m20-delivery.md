The public link contains a versioned whitelist: shop name/address/hours, public WhatsApp phone, delivery note, market/currency/timezone and up to twenty explicitly selected catalogue items. It uses lz-string Uint8Array compression and canonical base64url in `/app/s/#<payload>`. No customer, credit, stock, member or audit records enter the payload. Catalogue IDs identify only the selected public items. The decoder bounds the expanded text before parsing, and generation refuses an oversized link rather than dropping items. Both `/app/` and `/mise/app/` destinations are supported.

The existing schema-eight `Outlet.shopLink` stores the generated URL. The owner command checks the exact reviewed shop/catalogue values and previous link within one IndexedDB transaction, then saves the link and attributable audit together. Regeneration retains the shop code, creates a distinct edition even at the same timestamp, and snapshots current menu values. Ten-minute undo restores only the URL, preserves later shop edits, rejects a newer link and records its own audit. Undo cannot revoke links already copied to another device.

English and Bangla messages preserve pickup/delivery, address/time, customer name/phone, all literal item lines, optional payment preference and separate-photo intent. The final `#mise v1` footer adds an explicit photo bit; the handover's older sample remains accepted. A parsed message is an untrusted request, with no paid status or executable instructions.
