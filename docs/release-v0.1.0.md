Includes shared design tokens, self-hosted Bengali fonts, accessible mobile navigation, remembered region switching, installation instructions, self-hosting guide and a runtime download manifest.

Validation: lint, strict TypeScript, 9 unit/integration checks and 30 browser checks pass. Production builds work at `/` and `/mise/`; desktop and phone axe checks report no violations. Mobile Lighthouse scores: BD 96 / 100 / 96 / 100; Intl 98 / 100 / 96 / 100. CLS is about 0.001.

The app is a coming-soon screen. Accounts, offline app functionality, connected devices and AI operation follow the roadmap. There are no device binaries in this release. Product screenshots use the handover’s permitted HTML/CSS illustrations because Figma exports and connector access are unavailable. Contact/demo destinations remain owner configuration; the site displays an availability notice until configured.
