## What shipped

Shared token-based Button, Chip, Card, Section, Eyebrow, StatusWord and Lucide Icon primitives for Astro and React. Self-hosted Geist, Geist Mono and Hind Siliguri support Bengali text and taka. Tailwind uses the same variables.

The UI gallery at `/app/_ui?flags=uiGallery` is disabled by default. Visible keyboard focus and reduced-motion support are built in.

## Validation

Lint, strict type checks and build pass locally. Playwright verifies that the gallery is hidden by default, can be enabled, renders Bengali examples and supports keyboard focus. Core unit tests continue to pass.
