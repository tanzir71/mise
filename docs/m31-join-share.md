# Shares received before outlet setup

An empty device can receive a shared text or image before it has a shop, selected
member or cloud connection. Setup and the existing-outlet join screen now show a
count of those saved sources. The notice explains where to review them after
setup or joining, without showing their content during sign-in.
Local setup does not advertise joining while sync is disabled. Its five visual
checks use the share-target flag alone and verify that the join action is absent.

Joining an outlet keeps the source unassigned on that device. The user opens the
saved share in Inbox and chooses its destination explicitly. Original source and
image IDs, capture time, literal text and complete image bytes survive the join.
The claim records the current manager as its actor and creates the existing typed
capture in the same transaction as the source and audit. The source can be claimed
and cash recorded offline before the first ordinary canonical application.

The new browser proof starts two empty devices and uses the real phone-verification
and outlet-selection interfaces. The manager receives a multipart share through
the installed service worker while offline and before any business, operator,
binding, audit or queue exists. Its first ordinary pull is deliberately interrupted
after joining. An offline claim and cash sale then converge into the owner's
browser with the original source, complete image bytes and one financial record.
There is one manager OTP verification, no migration upload, no rewritten command
and no invented upload receipt. The unassigned source is absent from the owner's
device before the explicit claim.

SQL, HTTP, IndexedDB, service-worker capture and app controls run directly. Auth
verification, Realtime and object Storage are explicit local test adapters. The
HTTP gateway now permits the six production command headers and image PUT
preflights, allowing browser CORS enforcement to exercise the real handlers.
This does not commission SMS or prove installed Android acceptance.

The unit proof separately captures a source on an empty database before actual
manager admission, claims it before the first application and applies a fixed
download without rewriting the queue or adopting owner authority. Schema 21,
the 35 stores and the portable schema-10/21-table backup stay unchanged. Cloud
sync and share-target flags remain default off.

The [local verification record](m31-join-share-local.json) records passing lint,
strict TypeScript and 131 Astro files with no diagnostics, all 2,464 unit tests
across 135 files, 23 root-path browser tests and the full 443-test Pages-path
browser suite. There are no failed, flaky or skipped browser cases. Production
builds pass at `/` and `/mise/`. All 270 supplied exports are present.

overflow. The ten new setup/join captures pass serious/critical axe checks at
