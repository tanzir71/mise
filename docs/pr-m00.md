## What shipped

pnpm workspaces for Astro landing, React app, shared UI and core. Strict TypeScript, ESLint, Vitest, Playwright and a portable build producing `site/` and `site/app/`. CI checks pull requests, uploads the Pages artifact and deploys main. Device workflow remains dormant until native projects exist.

## Validation

`pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build`, `pnpm e2e` pass locally. CI repeats these with the `/mise/` base. Phase 0 app features are a coming-soon screen; no backend.
